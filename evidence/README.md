# Evidence policy

This repository favors public-safe, reproducible evidence over impressive-looking but unsafe screenshots.

## What may be added

- Output from a local, disposable test run with date, environment, and command recorded.
- Screenshots or videos created from a local learning project with no private data.
- Redacted examples where the owner has explicitly allowed publication.

## What must not be added

- Credentials, cookies, tokens, API keys, or `.env` files.
- Employer-only URLs, admin screens, source video, client data, participant records, or raw production logs.
- Screenshots that only hide a name while leaving a person, identifier, or sensitive context visible.

## Required caption for future evidence

Every evidence item should state: **source**, **environment**, **date**, **whether it is a planned or executed check**, and **what has been redacted**.

The absence of private screenshots is intentional. It protects the companies and people involved while keeping the portfolio honest.
