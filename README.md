# QA Engineering Portfolio

[![Portfolio validation](https://github.com/saltsnuff2204/qa-engineering-portfolio/actions/workflows/validate.yml/badge.svg)](https://github.com/saltsnuff2204/qa-engineering-portfolio/actions/workflows/validate.yml)

A practical collection of QA artifacts by **Alikhan Zhaxylyk**, a Junior QA Engineer and Software Engineering student with hands-on experience testing web, mobile, and AI-powered products.

## Professional focus

- Manual, functional, regression, smoke, and UI/UX testing
- Web, mobile, admin portal, and AI/Computer Vision validation
- REST API inspection with Postman and Swagger
- Client-side and network debugging with Chrome DevTools
- SQL checks for data integrity and business-rule validation
- Defect reporting, retesting, and lifecycle tracking in Jira and Trello
- Test design using boundary values, equivalence classes, decision tables, and error guessing

## System under test

The samples use the public [Restaurant Menu Manager](https://github.com/saltsnuff2204/restaurant-menu-manager), a local Java REST API, PostgreSQL database, and React dashboard. The artifacts contain no employer, client, participant, or production data.

- **Tech Support and QA Tester at BestYs:** web and mobile regression testing, API and DevTools investigation, SQL verification, defect management, and live-event support.
