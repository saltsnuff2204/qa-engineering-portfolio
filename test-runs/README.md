| Date | Scope | Result | Record |
| --- | --- | --- | --- |
| 2026-10-30 | Restaurant Menu Manager frontend: dependency install, lint, production build | Passed | [Frontend build verification](2026-10-30-frontend-build.md) |

When a run is added, record:

- date and tester;
- application revision or commit;
- local environment and test data source;
- executed scope;
- pass/fail/blocked counts;
- evidence location and known limitations.

This keeps test design separate from verified execution results.
